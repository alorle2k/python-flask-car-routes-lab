Flatiron Cars
Description

A simple Flask application that displays a welcome message and checks whether a requested car model exists in our fleet.

Routes
GET / — Displays "Welcome to Flatiron Cars!"
GET /<model> — Checks whether a car model exists in our catalog.
Example responses

Existing model: Flatiron Beedle is in our fleet!

Unknown model: No models called BMW exists in our catalog.

Installation
Clone the repository.
Install dependencies using pipenv install.
Activate the environment using pipenv shell.
Navigate to the server folder using cd server.
Run the application using python app.py.
